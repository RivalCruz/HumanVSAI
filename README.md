# Bele — Human or AI?

**Bele** is a responsive, browser-based media and information literacy game developed for the **UNESCO Youth Hackathon 2026**. The name _Bele_ means **“can”** in Tetun and represents the belief that young people and communities can build practical solutions to digital challenges.

Players examine text, images, and videos, then decide whether each item was created by a **human** or generated by **artificial intelligence**. After every choice, Bele provides a short explanation to help players reflect on the clues, sources, and reasoning behind the answer.

---

## Project Overview

Generative AI has made it increasingly difficult to distinguish authentic human-created information from synthetic media. Bele transforms media literacy education into an interactive guessing game instead of presenting users with passive guidelines.

The game is designed to help users practise four important habits:

1. **Observe** — inspect the wording, visual details, quality, and context.
2. **Question** — ask who created the content and why.
3. **Verify** — check sources, dates, evidence, and supporting information.
4. **Reflect** — consider the explanation before making future decisions.

Bele is intended for students, young people, educators, community members, and anyone who wants to improve their critical-thinking skills when consuming digital media.

## Main Features

- Responsive design for phones, tablets, and laptops
- Player-name entry and personalised game experience
- Beginner, Medium, and Hard difficulty levels
- Different countdown timers for each level
- Questions containing text, images, and videos
- Human-or-AI answer selection
- Immediate correct or incorrect feedback
- Short explanation displayed after every answer
- Full explanations and key points on the review page
- Live score and progress tracking
- Timed-out question handling
- Gold, silver, and bronze result levels
- About Us page with project information
- Five editable team-member profile cards
- Keyboard-friendly and accessible interface
- Object-oriented JavaScript structure
- API-based content with no quiz answers stored in the frontend
- Error handling for API, internet, image, and video problems

---

## How the Game Works

1. The player enters a name.
2. The player selects a difficulty level.
3. Bele requests quiz items from the API.
4. A question is displayed as text, an image, or a video.
5. The player chooses **Human** or **AI** before the timer ends.
6. Bele submits the choice to the answer API.
7. The player receives:
   - correct or incorrect feedback;
   - the correct classification;
   - a short explanation.
8. After all questions, Bele displays the final score and medal.
9. The player can review every question, explanation, source, and key point.
